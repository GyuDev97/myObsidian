# Rust 운영체제 개발

운영체제 실험은 하드웨어·부트 과정·인터럽트·메모리·렌더링이 애플리케이션 아래에서 어떻게 맞물리는지 이해하게 한다.

## 프로젝트 연결

[[Projects/GyuOS v0.1]]은 Rust `no_std` x86_64 커널, UEFI 부팅 이미지, 프레임버퍼 렌더링, PIC/PIT와 PS/2 입력, 간단한 데스크톱 셸을 직접 구현한 교육용 프로젝트다.

## 현재 경계

이 버전은 메모리 할당자·가상 메모리·스케줄러·파일 시스템·네트워크 등을 아직 구현하지 않았다는 경계를 명확히 한다. 이런 ‘무엇을 하지 않는가’의 기록은 [[Ideas/프로젝트 경험을 지식으로 전환하기]]에 좋은 재료다.
