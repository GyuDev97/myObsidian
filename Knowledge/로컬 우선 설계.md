# 로컬 우선 설계

핵심 데이터와 작업 상태를 먼저 사용자 기기 또는 사용자가 관리하는 환경에 두고, 동기화·공유·분석은 명시적인 필요와 동의가 있을 때 추가하는 설계 관점이다.

## 이 프로젝트들에서 보이는 적용

- [[Projects/TrailGO]]는 게스트 라이딩 기록과 GPX를 기기에 저장하고 자동 업로드하지 않는다.
- [[Projects/내 맘대로컷]]은 원본 미디어 대신 Project JSON을 편집 상태의 기준으로 둔다.
- [[Projects/WorkMemory]]는 로컬 폴더의 자료 메타데이터 수집을 제공하고 원본·인덱스는 Git에서 제외한다.
