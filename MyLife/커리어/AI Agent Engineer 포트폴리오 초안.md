# Profile

사용자 맥락을 이해하고 실행까지 이어지는 AI Agent 제품을 설계·구현합니다. 에이전트의 도구 호출, RAG·메모리, 업무 워크플로와 제품 경험을 함께 다룹니다.

## Core strengths

- **Agent design** — 역할·도구·실행 흐름 설계
- **Context & memory** — 검색·기억·개인화 경험 구현

## Product delivery

- **End-to-end build** — 사용자 흐름부터 배포까지
- **Workflow automation** — 반복 업무를 실행 가능한 경험으로 전환

# Selected Work

> 
각 프로젝트는 **문제 → 해결 방식 → 나의 기여 → 검증 가능한 결과** 순서로 읽히도록 구성합니다. 이 페이지에는 공개 가능한 사실만 남깁니다.

## 01. GyuNexus

**AI Agent를 중심으로 한 대표 프로젝트**

- **Problem** — \[해결하려던 사용자 문제를 한 문장으로\]
- **Solution** — \[Agent 역할, 입력·출력, 연결한 도구 또는 데이터\]
- **Contribution** — \[직접 설계·개발한 범위\]
- **Evidence** — \[공개 가능한 데모·저장소·화면·검증 결과\]

> 제출용에는 핵심 화면 2장과 간단한 아키텍처 다이어그램을 추가합니다.

## 02. WorkMate / WorkMemory

**업무 맥락을 저장하고 필요한 순간에 활용하는 제품**

- **Problem** — \[반복 업무 또는 맥락 단절 문제\]
- **Solution** — \[WorkMate와 WorkMemory의 역할, 기억의 저장·검색·갱신 흐름\]
- **Contribution** — \[본인이 담당한 제품·Agent·UI·Backend 범위\]
- **Evidence** — \[공개 가능한 사용자 흐름·기술 근거·데모\]

## 03. 고급유노트

**지식 관리 경험에 AI를 결합한 프로젝트**

- **Problem** — \[대상 사용자와 해결하려던 정보 관리 문제\]
- **Solution** — \[지식 정리·검색·AI 기능\]
- **Contribution** — \[담당 범위\]
- **Evidence** — \[핵심 화면·링크·검증 가능한 결과\]

## 04. TrailRide

**도메인 문제를 제품으로 해결한 사례**

- **Problem** — \[사용자 또는 시장의 문제\]
- **Solution** — \[제품 가설과 구현 방식\]
- **Contribution** — \[담당 범위\]
- **Evidence** — \[화면·데모·검증 가능한 결과\]
