# TrailGo MVP 작업 정리 및 로드맵

> Notion 원본: https://app.notion.com/p/3f66bc51992b812aa41ee2b834cbefe1?pvs=204
> Notion 최종 수정: 2026-10-13T02:57:18.915Z
> 검증 상태: unverified

> **목적:** Google Play 출시용 TrailGo를 게스트 로컬 주행 MVP로 안정화하고, 이후 소셜 로그인 기반 회원 동기화로 확장한다.

# 현재 제품 방향

- 핵심 사용자: MTB 라이더
- MVP 가치: GPS 주행 기록, GPX 코스 따라가기, 기기 내부 기록 저장·조회
- 출시 우선순위: **게스트 로컬 기능**
- 서버 역할: 공개 코스 GPX, 승인된 위험지역, 운영자 위험지역 검수
- 회원 동기화·커뮤니티 기능은 인증과 권한 모델이 완료될 때까지 비노출

# 이번에 완료한 작업

## 게스트 주행·저장

- 주행 종료 후 기록 요약과 GPX를 기기 내부에 저장
- 게스트 기록은 항상 비공개이며 서버에 전송하지 않음
- 기록 목록, 상세 조회, 로컬 GPX 열기, 삭제를 기기에서 처리
- 미완료 주행 체크포인트와 경로 캐시를 통해 앱 종료·복구에 대응
- 저장 파일과 인덱스는 원자적 저장 방식을 사용해 부분 저장 가능성을 줄임

## GPS 기록 안정화

- 위치 요청을 고정밀 Fused Location 우선으로 변경하고 GPS 공급자를 보조 수단으로 유지
- 주행 기록 책임을 서비스·로컬 저장 경로 중심으로 정리
- 위치마다 발생하던 지도 카메라 이동·역지오코딩·객체 누적을 줄임
- 화면 잠금과 앱 전환 중에도 포그라운드 서비스로 기록을 지속하도록 정비

## 게스트 화면과 설정

- 앱 시작은 게스트 모드를 우선 사용
- 게스트 드로어 프로필은 로그인 화면 대신 로컬 앱 설정으로 이동
- 게스트 설정에서 로그인·회원가입 진입을 숨김
- 게스트 개인정보 화면에 “기기 전용·비공개 저장”을 표시
- 실제 동작과 연결되지 않았던 설정의 GPX 가져오기·내보내기 메뉴를 비노출
- Strava·Garmin·Komoot 등 외부 연동은 게스트 MVP에서 비노출
- GPX 코스 가져오기는 코스 탭의 실제 기능으로 유지

## 서버·보안 정비

- 서버 설정의 DB·관리자·외부 API 비밀값을 환경 설정 방식으로 이동
- 공개 API를 공개 코스와 승인·활성 위험지역 조회로 제한
- 위험지역은 승인 상태이면서 활성·미만료·미병합인 항목만 앱에 제공
- 레거시 회원·기록 API는 외부 인증 없이 열지 않도록 차단
- 앱 서버 주소는 빌드 설정에서 주입하도록 유지

# 소셜 로그인 설계 원칙

```txt
Android 앱 → 카카오/네이버 SDK 로그인
          → 공급자 access token
          → TrailGo 서버의 소셜 로그인 교환 API
          → 공급자 토큰 검증 및 계정 연결
          → TrailGo 전용 access/refresh token 발급
          → /api/v1/me 및 /api/v1/me/rides 호출
```

- 공급자 비밀번호는 TrailGo 서버에 저장하지 않는다.
- 카카오·네이버 토큰을 TrailGo API 인증 토큰으로 재사용하지 않는다.
- 공급자 Client Secret 같은 비밀값은 서버 환경 설정에만 저장한다.
- 네이티브 앱 키, 패키지명, 서명 해시 등 앱 등록값은 개발자 콘솔과 배포 서명을 기준으로 관리한다.
- 게스트 원본 기록은 먼저 로컬에 안전하게 저장하고, 동기화는 사용자의 명시적 선택 이후에만 한다.

# 현재 상태 요약

> 
게스트 MVP를 우선으로 동작 경로를 정리했으며, Android 컴파일과 단위 테스트를 통과했다. 회원 기능은 현재 비노출 상태로 유지한다.

> 
회원 로그인·서버 기록 동기화는 HTTPS와 안전한 소셜 인증·소유권 검증이 완료되기 전에는 공개하지 않는다.
